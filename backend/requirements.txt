# Notebook penelitian dijalankan pada Python 3.10.0 dengan transformers 4.44.0
# dan torch 2.13.0+cpu (lihat output cell 1 & source cell 2).
#
# transformers sengaja TIDAK dipin ke 4.44.0. Alasannya:
#
#   transformers 4.44.0 mensyaratkan tokenizers >=0.19,<0.20. tokenizers adalah
#   ekstensi Rust, dan 0.19.x terbit sebelum Python 3.13 sehingga tidak punya
#   wheel cp313. Pada Python 3.13 pip terpaksa membangunnya dari sumber, gagal
#   menyiapkan toolchain Rust, lalu seluruh instalasi berhenti dengan
#   'metadata-generation-failed'. Pin itu membuat `pip install -r` mustahil
#   berhasil di Python 3.13 — termasuk pada mesin pengembangan proyek ini.
#
# Yang menggantikan pin: bukti empiris, bukan asumsi.
# training/verify_reproduction.py membandingkan hasil versi yang benar-benar
# terpasang dengan output notebook sampai level elemen — 876 nilai ground-truth
# dan 876 keputusan prediksi test set, ditambah metrik presisi penuh. Kalau
# versi transformers yang terpasang mengubah perilaku tokenizer atau model
# sedikit saja, pemeriksaan itu gagal. Verifikasi terakhir: 34/34 lolos pada
# transformers 4.57.6 / Python 3.13.14 / torch 2.13.0+cpu.
#
# Jadi: pakai Python 3.10-3.12 kalau ingin lingkungan persis notebook, atau
# Python 3.13 dengan transformers terbaru — lalu JALANKAN verifikasinya:
#
#   .venv\Scripts\python training/verify_reproduction.py
#   .venv\Scripts\python backend/test_pipeline.py
# Batas atas <5 ditambahkan setelah build Railway 2026-08-06 memasang
# transformers 5.14.1 dan gagal. Alasannya bukan sekadar build yang merah:
# seluruh verifikasi di atas dijalankan pada lini 4.x, sehingga 5.x adalah
# versi mayor yang belum pernah diadu dengan output notebook. Angka yang
# ditampilkan UI adalah metrik hasil notebook; melayani model di atas
# transformers yang perilakunya belum diperiksa membuat angka itu menjadi
# klaim, bukan pengukuran. Naikkan batas ini hanya setelah
# training/verify_reproduction.py lolos pada versi yang baru.
fastapi>=0.115
uvicorn[standard]>=0.34

transformers>=4.44,<5
